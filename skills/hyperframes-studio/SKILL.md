# Hyperframes Studio Skill

Origin: `heygen-com/hyperframes`

Hyperframes Studio provides an in-browser timeline scrubbing interface for reviewing video choreography, inspecting element bounding boxes, and testing responsive text bounding.

---

## 1. Studio Features
- **Scrub Bar:** Drag along the frame track to inspect animation poses at any sub-frame.
- **Speed Multiplier:** Playback at 0.25x or 0.5x speed to evaluate easing curves and optical settle.
- **Safe Area Overlays:** Toggle action-safe and title-safe guidelines for broadcast television and social platform UI chrome.
- **Snapshot Export:** One-click PNG capture of the currently displayed frame.
