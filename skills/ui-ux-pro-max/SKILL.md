# UI/UX Pro Max Skill

Origin: `nextlevelbuilder/ui-ux-pro-max-skill`

This skill provides comprehensive user experience intelligence and interface design guidelines for modern web applications.

---

## 1. Interaction Heuristics (Nielsen-Norman Adapted)
1. **Visibility of System Status:** Always confirm user input within 100ms with visual or haptic feedback.
2. **Match Between System and Real World:** Use words, phrases, and concepts familiar to the target audience rather than internal technical jargon.
3. **User Control & Freedom:** Clear, visible exit paths (Close buttons, Escape key handler, Cancel links).
4. **Consistency & Standards:** Follow platform conventions so users do not have to wonder whether different words, gestures, or actions mean the same thing.
5. **Error Prevention & Recovery:** Clear inline validation; helpful error messages indicating exact remediation.

---

## 2. Touch & Responsive Ergonomics
- **44x44px Minimum:** Touch targets must be at least 44x44px.
- **Thumb Zone Optimization:** Primary actions situated in the reachable thumb arc on mobile devices.
- **Form Layout:** Single-column forms for mobile; inputs paired with explicit labels and clear hit regions.

---

## 3. Cognitive Load Reduction
- Chunk complex processes into digestible milestones.
- Keep primary navigation choices under 7 options.
- Establish clear visual hierarchies: 1 primary CTA per viewport, secondary links clearly subdued.
