# Minimalist UI Skill

Origin: `Leonxlnx/taste-skill`

Minimalism is not the absence of design; it is the absolute precision of what remains. Every pixel, line, and character must justify its presence.

---

## 1. Core Principles (Dieter Rams / Swiss Style)
1. **Content is the Interface:** Let headings, data, and authentic copy drive the composition.
2. **Whitespace as Structure:** Generous negative space guides the eye far more effectively than divider lines or container boxes.
3. **Monochrome Foundation:** Build with black, white, and calibrated gray tones. Introduce at most one intentional accent color for interactive feedback.
4. **Typographic Grid:** Align elements strictly to a cohesive baseline grid.

---

## 2. Practical Implementation Rules
- **No Card Packaging:** Display content directly on the canvas without wrapping every item in a bordered card.
- **Micro-borders:** Where division is required, use 1px solid borders with minimal opacity (`border: 1px solid rgba(0, 0, 0, 0.06)`).
- **Subtle Interactions:** Hover states use gentle contrast shifts or underline reveals rather than bouncy transforms or bright color blooms.
- **Fast and Lightweight:** Zero unneeded JS dependencies; fast rendering with clean semantic HTML.
